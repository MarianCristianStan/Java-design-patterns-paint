# Java Design Patterns Paint

This is an older university project that I built while learning and practicing software design patterns in Java.

The application is a simple Paint-style program and was mainly used as a practical way to understand how different design patterns can be applied.

Some of the patterns explored in this project include:

- Command
- Decorator
- Facade
- Interpreter
- Iterator
- Memento
- Observer
- Strategy

The project was originally created as part of my university coursework!
